# Security policy

Porch is pre-alpha. Do not rely on it for anything important yet.

## Reporting a vulnerability

Please report privately via GitHub Security Advisories on `aurimasniekis/go-porch` ("Report a vulnerability").
Do not open public issues for security problems. You will get an acknowledgement within 7 days.

## Scope

In scope: authentication, session handling, OIDC provider behaviour, tenant isolation, authorization decisions,
forward-auth, key management, backups, audit integrity. The threat model and its explicit non-goals are in
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
